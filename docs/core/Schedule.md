# Клас Okay\Core\Scheduler\Schedule

Клас призначений для реєстрації завдання в планувальнику задач.

Приймає в конструктор завдання, яке може мати такий вигляд:

Вид | Формат | Приклад
---|---|---
Команда для виконання в терміналі. | Рядок | `whoami`
Callable-обʼєкт. Клас може бути як сервісом, так і звичайним класом. Метод може бути статичним або звичайним. | Масив `[ClassName::class, 'methodName']` | `[NPCacheHelper::class, 'cronUpdateCitiesCache']`
Анонімна функція | Closure | `function (ProductsEntity $productsEntity): void { $productsEntity->update(1, ['visible' => 1]); }`

Аргументи методу або анонімної функції будуть резолвитися автоматично на підставі type hint і значень за замовчуванням.

### Методи

```php
name(string $name)
```
Метод приймає назву завдання

```php
time(string $time)
```
Метод приймає патерн часу виконання завдання. Формат часу й правила виконання аналогічні задачам у CRON.
Приклади:

0 * * * * - Виконання завдання 1 раз на годину о 0 хвилин

0 0 * * * - Виконання завдання 1 раз на добу о 00:00

```php
timeout(int $timeout)
```
Максимальний час виконання завдання в секундах. Після спливу часу завдання буде завершене в аварійному режимі.

```php
overlap(bool $value = true)
```
За замовчуванням допускається виконання більш ніж одного екземпляра завдання. Якщо викликати метод і передати false, одночасно виконуватиметься не більше 1 екземпляра.
