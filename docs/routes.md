# Маршрути (Routes)

За допомогою маршрутів система визначає, якому контролеру потрібно передати керування для обробки запиту.
Маршрути в системі описуються у файлі `Okay/Core/config/routes.php`.
Ключ масиву — це імʼя маршруту.
Значення — опис маршруту.

Маршрут являє собою масив такого вигляду:
```php
[
    'slug' => 'url_маршруту{$іменований_параметр}',
    'patterns' => [
        '{$іменований_параметр}' => 'регулярний_вираз_параметра',
    ],
    'params' => [
        'controller' => 'імя_використовуваного_класу_контролера',
        'method'     => 'імʼя_викликаного_методу_контролера',
    ],
    'defaults' => [
        '{$імя_параметра_за_замовчуванням}' => 'значення_параметра_за_замовчуванням',
    ],
    'to_front' => true|false, // чи потрібен цей маршрут як JS-змінна на фронтенді. У JS його можна буде побачити як okay.router['<route_name>'],
    'overwrite' => true|false, // чи може цей маршрут перевизначати маршрут, розташований вище, за однакових назв,
    'always_active' => true|false, // завжди активний. Коли встановлено true, навіть за вимкненого сайту цей маршрут буде активний,
];
```

Приклад:
```php
return [
    'cart_remove_item' => [
        'slug' => '/cart/remove/{$variantId}',
        'params' => [
            'controller' => 'CartController',
            'method' => 'removeItem',
        ],
        'patterns' => [
            '{$variantId}' => '([0-9]+)',
        ],
    ],
];
```

Усі маршрути обробляються зверху вниз — до першого, чий slug відповідає поточному URL.
Усі параметри, оголошені як `{$var}`, для яких не вказано pattern, за замовчуванням мають вираз `([^/]+)`.
Також параметри, вказані як `{$var}`, можна [отримувати в методі контролера](./controllers.md#routeVars).

Також маршрути можна додавати з [модуля](./modules/README.md). Для цього потрібно описати маршрути за такою ж структурою,
як і стандартні, але у файлі `Okay/Modules/Vendor/Module/Init/routes.php`.

### Генерація URL

Router може на підставі даних маршруту генерувати URL. Завдяки цьому можна абстрагуватися від структури
URL, що робить систему гнучкішою.
Для генерації URL в OkayCMS є статичний метод `Router::generateUrl()`.
Метод `generateUrl()` приймає такі аргументи:
* `$routeName` — string назва маршруту, на підставі якого потрібно будувати URL
* `$params` — array асоціативний масив даних, які потрібно підставити в маршрут.
Ключем має бути імʼя параметра. Наприклад, для slug `/cart/remove/{$variantId}` масив має бути `['variantId' => 1]`
* `$isAbsolute` — bool ознака абсолютного URL. За замовчуванням false
* `$langId` — int id мови, для якої потрібно побудувати маршрут. Якщо для поточної — можна не вказувати.

Також для Smarty є плагін-обгортка для цього методу — `{url_generator}`.
Він може приймати параметри:
* `route` — string назва маршруту
* `absolute` — bool|int ознака абсолютного URL. За замовчуванням false
* інші параметри, які будуть передані в аргумент `$params` методу `generateUrl()`.

Приклад побудови URL для маршруту `cart_remove_item` (опис вище):

PHP
```php
use Okay\Core\Router;

$url = Router::generateUrl('cart_remove_item', ['variantId' => 1], true); // http://domain.com/cart/remove/1
```

Smarty
```smarty
{url_generator route='cart_remove_item' variantId=132 absolute=1}
```

### Отримання інформації про поточний маршрут

Щоб отримати інформацію про поточний маршрут, у класу Router є такі методи:
* `getCurrentRouteName()` — повертає імʼя поточного маршруту
* `getCurrentRouteRequiredParams()` — повертає всі обовʼязкові параметри, для яких не задано type hint (текстові),
у вигляді асоціативного масиву; вони вказані в полі slug маршруту
* `getCurrentRouteParams()` — повертає всі параметри, для яких не задано type hint (текстові),
у вигляді асоціативного масиву; вони вказані в полі slug маршруту
* `getRouteByName($routeName)` — отримати всю інформацію про вказаний маршрут
