# Планувальник завдань

У системі є планувальник завдань, який дозволяє налаштовувати виконання певних задач у заданий час.

Для роботи планувальника в системний cron потрібно додати виконання такої задачі:
```
* * * * * php path-to-your-project/ok scheduler:run
```
де `path-to-your-project` — абсолютний шлях до директорії вашого проєкту.

Щоб зареєструвати задачу в модулі, потрібно використати метод `registerSchedule` всередині методу `Init`. Метод приймає обʼєкт класу [Schedule](./core/Schedule.md).

Приклад:
```php
class Init extends AbstractInit
{
    public function init()
    {
        $this->registerSchedule(
            (new Schedule([NovaposhtaCost::class, 'parseCitiesToCache']))
                ->name('Parses NP cities to the db cache')
                ->time('0 0 * * *')
                ->overlap(false)
                ->timeout(3600)
        );
    }
}
```

Логи роботи можна знайти у файлі `log/scheduler/scheduler.log`.

### Взаємодія з планувальником
Для взаємодії з планувальником потрібно використовувати консольний helper у директорії проєкту.

```
php ok scheduler:run [-f|--force]
```
Запускає виконання всіх задач, які можуть бути виконані з огляду на правила часу та перетину. Якщо використати ключ `-f`, усі задачі будуть виконані “примусово”, в обхід правил.

```
php ok scheduler:list
```
Виводить список усіх зареєстрованих задач у табличному вигляді.
Приклад:
```
+----+--------------------------------------+-----------+----------------------------------------------------------------------------+
| id | Name                                 | Time      | Command                                                                    |
+----+--------------------------------------+-----------+----------------------------------------------------------------------------+
| 1  | Parses NP cities to the db cache     | 0 0 * * * | Okay\Modules\OkayCMS\NovaposhtaCost\NovaposhtaCost::parseCitiesToCache     |
| 2  | Parses NP warehouses to the db cache | 0 0 * * * | Okay\Modules\OkayCMS\NovaposhtaCost\NovaposhtaCost::parseWarehousesToCache |
+----+--------------------------------------+-----------+----------------------------------------------------------------------------+
```

```
php ok scheduler:task [-f|--force] <task_id>
```
Запускає виконання конкретної задачі, якщо вона може бути виконана з огляду на правила часу та перетину. Приймає id задачі. Якщо використати ключ `-f`, задача буде виконана “примусово”, в обхід правил.
