## Про цей форк

Це незалежна версія OkayCMS на основі **офіційного останнього релізу**.

Головна мета — зробити систему сучасною та безпечнішою:

- оновити проєкт під актуальну версію PHP;
- оновити всі залежності й сторонні бібліотеки до актуальних версій або замінити їх на сучасні аналоги, які ще підтримуються;
- виправити знайдені помилки та проблеми безпеки, виявлені під час оновлення коду.

Іншими словами: зберегти звичну OkayCMS, але з сучасним технічним фундаментом і виправленими відомими ризиками.

Інформація про всі поточні та заплановані зміни знаходиться в файлі [CHANGELOG.md](CHANGELOG.md).
