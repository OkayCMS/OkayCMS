# module.json

Файл module.json призначений для додавання модулю супровідної мета-інформації: версії модуля,
контактних даних розробника, [модифікацій tpl файлів](./../tpl_modifiers.md).

Цей файл розташований у директорії [Init](./init.md) вашого модуля. Файл має містити JSON-опис модуля.
Обовʼязкові директиви:

Директива | Опис
---|---
version | Поточна версія модуля. Якщо версію модуля не вказано — вважається, що це версія 1.0.0
vendor->email | Контактний e-mail розробника.
vendor->site | Сайт розробника.

Опціональні директиви:

Директива | Опис
---|---
modifications | Містить [модифікації tpl файлів](./../tpl_modifiers.md) модуля.

### Версіонування модуля

Версії модуля мають складатися з трьох цілих чисел, розділених крапкою. Першою вважається версія 1.0.0.

Якщо зміни модуля стосуються лише невеликих фіксів — збільшується третя цифра версії на одиницю.

Якщо зміни стосуються логіки роботи модуля або модуль несумісний із попередніми версіями OkayCMS — потрібно інкрементувати на одиницю другу цифру, а третю скинути в 0.

Якщо модуль повністю переробляється — потрібно інкрементувати першу цифру, а другу і третю скинути в 0.
